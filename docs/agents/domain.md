# Domain documentation

This repository uses a **single-context** layout:

- `CONTEXT.md` is the living domain glossary and project context.
- `docs/adr/` contains durable architectural decisions.

Agents should read `CONTEXT.md` before changing domain terminology or system boundaries, then read relevant ADRs before making a decision that is difficult to reverse. Keep `CONTEXT.md` concise and update it when the shared language changes.
